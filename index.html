A smartphone is more than just a screen.

A modern mobile device is a complete computing system packed into a small enclosure.

Hardware receives physical input, processors execute instructions, memory temporarily stores information, and the operating system coordinates everything.

Applications sit above this foundation and use operating-system services and APIs to interact with the device.
