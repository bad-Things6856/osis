Electronics: a short history

Electronics is the science of controlling the flow of electrons to do useful work, like playing sound, showing pictures, or doing calculations. It started big and clumsy, and slowly became small and clever.

  • 1904

    The vacuum tube

    John Ambrose Fleming invents the first vacuum tube diode. Radios and early computers used these glass tubes. They were big, hot and burned out often.

  • 1947

    The transistor

    Scientists at Bell Labs build the first transistor. It does the job of a tube but is smaller, cooler and much more reliable.

  • 1958

    The integrated circuit

    Jack Kilby shows that many parts can be built on one small piece of material. This is the "chip", and it changed everything.

  • 1971

    The microprocessor

    Intel releases the 4004, a whole processor on one chip. Computers could now become small and cheap.

  • 1970s

    The first microcontrollers

    Companies like Texas Instruments and Intel put a processor, memory and input/output pins together on a single chip. Now one small part could run a whole gadget.

  • 2005

    Arduino

    A cheap, friendly board built for students. Anyone could now write a few lines of code and make an LED blink or a robot move.

  • 2010s

    Wi-Fi chips and Raspberry Pi

    Chips like the ESP8266 and ESP32 add Wi-Fi for a few dollars. The Internet of Things (IoT) takes off: smart bulbs, sensors, and connected devices.

  • Today

    Tiny chips with AI

    Modern microcontrollers can run small machine learning models, listen for voice commands, and last for months on a battery. Open designs like RISC-V are also growing fast.

What is a microcontroller?

A microcontroller (MCU) is a tiny computer on a single chip. It has a processor, a little memory, and pins that connect to the outside world. You write a program, load it once, and it keeps running the same job again and again.

Microcontroller vs microprocessor

MicrocontrollerMicroprocessor
What it isWhole small computer on one chipOnly the processing part (CPU)
MemoryBuilt inExternal chips needed
Power useVery lowHigh
Best forOne specific jobGeneral computers, phones
ExampleArduino Uno, ESP32Laptop or PC processor

Popular microcontroller boards

  • Arduino Uno - best for beginners, huge community.
  • ESP32 - has Wi-Fi and Bluetooth, great for IoT projects.
  • Raspberry Pi Pico - cheap and easy, works with C and MicroPython.
  • STM32 - powerful chips used in many real products.

How to get started

  1. Buy an Arduino Uno or ESP32 board and a USB cable.
  2. Install the free Arduino IDE.
  3. Upload the "Blink" program below.
  4. Then try a button, a sensor, or a small motor.

Here is the classic first program. It turns the built-in LED on and off every second:

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // LED on
  delay(1000);                      // wait 1 second
  digitalWrite(LED_BUILTIN, LOW);   // LED off
  delay(1000);
}

If you already know basic C, you are ahead. Arduino code is just C/C++ with some helpful functions added.
