01 / PROCESSING

The CPU

The Central Processing Unit executes program instructions, performs calculations and coordinates operations within a computer. Its performance depends on more than clock speed: architecture, core count, cache and power limits matter too.

CPU / INTERNAL UNITS

The ALU handles arithmetic operations and logical comparisons.

02 / PORTABLE COMPUTING

Inside a laptop

A laptop is a balance between performance, battery life, temperature and size. Its processor shares a limited power and cooling budget with the rest of the system.

Cooling

Heat pipes, fans or vapor chambers move heat away from hot components.

Memory

RAM holds active programs and data so the CPU can access them quickly.

Power

Processors adjust their operating speed and power to meet workload and thermal limits.

03 / INTEGRATED HARDWARE

Microprocessors

A microprocessor is an integrated circuit that implements a processor. Modern chips can contain multiple CPU cores, cache and other supporting hardware.

A microcontroller goes further by integrating a processor with memory and peripherals such as timers, communication interfaces and GPIO. This makes it useful for embedded systems and electronics projects.
